New versions use **the same file name** as the previous one (for example `PolloverseDream_1.0.0_RC5.gba`), so your emulator loads your `.sav` automatically.

1. Download the new ROM.
2. Replace your old `.gba` with the new one, **in the same folder** and with the **same name**.
3. Open the game and pick **CONTINUE**. ¡Dale! 💪

If the name changed between versions, rename your `.sav` so it matches the new `.gba`.
